## ✨ About the Project

**BUBZO** is a vibrant, beautifully crafted brand website for a freshly-made soda company born in Bengaluru. It celebrates the soul of India's street-side soda culture — from the zesty *Bengaluru Nimbu Soda* to the bold *Andhra Masala Soda* — and presents it through a polished, modern, and joyful digital experience.

The entire website lives in **one elegant, self-contained HTML file**: no frameworks, no build tools, no dependencies to wrestle with. Open it, and the magic begins.

## 🗂️ Pages & Experience

### 🏠 Home
A radiant, gradient-rich hero welcomes visitors with the brand promise, floating product imagery, and trust badges — *Fresh Made to Order*, *Naturally Cooling*, *RO Water Used*, and *Zero Sugar Options*. Below, discover the five **Popular Flavours**, a showcase of **Regional Flavours of India**, brand-promise highlights, and an Instagram community call-to-action.

### 🍹 Flavours
The complete BUBZO menu in one place. Browse the full collection or refine instantly with dynamic category filters. Every card features a vivid visual, a price tag, a tasting note, and a one-tap **Add to Cart**.

### 💚 About Us
The BUBZO story — from a 2020 Bengaluru dream to a beloved South Indian brand. Features milestone statistics (**50+ outlets · 20+ flavours · 5L+ happy customers · 6 years of fizz**), six core brand values, and an introduction to the leadership team.

### 🚀 Franchise
An inviting gateway for aspiring entrepreneurs: a clear **4-step process** (Apply → Discovery Call → Agreement & Training → Launch), three transparent **investment plans**, and a comprehensive enquiry form.

### 📞 Contact
Everything needed to connect: phone, email, headquarters address, social handle, a message form with subject routing, an embedded **Google Map**, and an expandable **FAQ** section.

## 🛠️ Technology Stack

- **HTML5** — clean, semantic structure

- **Vanilla JavaScript** — zero dependencies, lightweight and lightning fast
- **Google Fonts** — *Poppins* for bold headlines, *Nunito* for friendly body text

## 🚀 Getting Started

No installation. No build step. Simply:

```bash
# 1. Download or clone the project
git clone <your-repository-url>

# 2. Open the file in any modern browser
open bubzo-website.html        # macOS
start bubzo-website.html       # Windows
xdg-open bubzo-website.html    # Linux
```

Or serve it locally for a more production-like experience:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

> 💡 An internet connection is required to load fonts, images, and the embedded map.

## 🧩 Project Structure

```
bubzo-website/
├── bubzo-website.html    # Complete website: markup, styles, and scripts
└── README.md             # You are here
```

Inside the HTML file:

| Section | Purpose |
|---|---|
| `<style>` | Design tokens, layout, components, animations |
| `<body>` pages | `page-home`, `page-flavours`, `page-about`, `page-franchise`, `page-contact` |
| `<script>` | Flavour data, filtering, cart logic, navigation, FAQ, forms, toasts |

### Key JavaScript Functions

| Function | What it does |
|---|---|
| `navigate(page)` | Switches between pages smoothly |
| `renderFlavours(filter)` / `filterFlavours()` | Builds and filters the menu grid |
| `addToCart()` / `removeFromCart()` / `changeQty()` | Manages cart contents |
| `renderCart()` / `toggleCart()` | Updates and shows the cart panel |
| `toggleFaq()` | Expands and collapses FAQ answers |
| `showToast()` | Displays elegant notifications |
| `submitFranForm()` / `submitContact()` | Handles form submissions |

## 🔧 Customisation Guide

**Add a new flavour** — append an entry to `ALL_FLAVOURS`:

```js
{name:'Guava Chilli Fizz', price:55, cat:'seasonal',
 color:'var(--pink)', bg:'var(--pink)',
 img:'YOUR_IMAGE_URL', desc:'Sweet guava with a spicy kick.'}
```

**Change the brand colours** — edit the variables in `:root`:

```css
:root { --gd:#1a4d2e; --gl:#4caf50; --orange:#ff6b00; }
```

**Update contact details** — search for `hello@bubzo.in` and `+91 98765 43210` and replace them with your own.
